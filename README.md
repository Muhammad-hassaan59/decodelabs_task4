# Data Analytics Project 4 – Visualization

## 📌 Overview
This project demonstrates how to transform raw sales data into clear, actionable insights using **Power BI**.  
The dataset is provided in CSV format (`Dataset for Data Analytics.csv`) and contains order details such as product, quantity, price, payment method, referral source, and order status.

## 📂 Files
- `Dataset for Data Analytics.csv` → Raw sales transactions data.
- `README.md` → Project instructions and usage guide.

## ⚙️ Steps to Reproduce
1. Open **Power BI Desktop**.
2. Import `Dataset.csv` via **Home → Get Data → Text/CSV**.
3. Clean and prepare data:
   - Convert `Date` column to Date type.
   - Ensure numeric columns (`Quantity`, `UnitPrice`, `TotalPrice`) are set as Decimal.
   
4. Build visuals:
   - **Clustered Bar Chart** → Revenue by Product.
   - **Line Chart** → Sales trend over time.
   - **Donut Chart** → Order Status distribution.
   - **Key Influencer Visual** → Factors driving cancellations or high revenue.


## ✅ Goal
Turn raw CSV data into a **boardroom-ready visual story** that drives business decisions.
